# 🚆 RailBot — Indian Railways AI Assistant

RailBot is an AI-powered Indian Railways assistant that helps users access railway information through a conversational interface.

The system integrates Claude AI with Railway APIs to provide real-time train-related information including PNR status, seat availability, Tatkal quota details, train schedules, station codes, and class references.

---

# ✨ Features

## 🤖 AI Assistant
- Conversational railway assistant
- Claude AI integration
- Intelligent query handling
- Railway-focused responses

## 🚉 Railway Services
- PNR status lookup
- Seat availability checking
- Tatkal quota reference
- Train schedule assistance
- Station code lookup
- Railway class code reference

## 🎨 User Interface
- Modern dark-themed UI
- Interactive dashboard
- Quick action railway cards
- Real-time responses
